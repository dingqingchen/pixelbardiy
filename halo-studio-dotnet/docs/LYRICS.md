# 歌词时间轴与长句分页（2.6.0）

当前桌面播放、歌词解析、分页和 USB 调度均由 C# 完成，不启动 Python 服务。Python 保留于旧版和固件工程工具中。

## 歌词来源

1. 手动导入的 LRC 优先，作为用户指定版本。
2. 核对网易云当前歌曲 ID，从 `api/song/lyric/v1` 获取 YRC 与 LRC。中文通常提供逐字时间，英文通常提供逐词时间；并非每首歌都有 YRC。
3. YRC 缺失或格式/时序校验失败，使用同一歌曲 ID 的 LRC；接口不可用时可使用已经保存的版本缓存或旧歌词接口。缓存按 ID 隔离，避免同名歌曲的不同分句相互覆盖。
4. 没有可信时间轴时使用播放器当前句。未知的未来歌词不会被猜测生成。

接口字段参考 [API Enhanced 的 lyric_new 模块](https://github.com/neteasecloudmusicapienhanced/api-enhanced/blob/master/module/lyric_new.js)，解析器独立实现。接口可能变化或返回无逐字数据。本机已有精确 ID 的旧缓存首次联网会尝试补齐 YRC；有缓存后离线可用，不按帧请求网络。

YRC 的 `[句开始毫秒,句时长毫秒](词开始毫秒,词时长毫秒,标记)文字` 使用绝对歌曲时间。程序校验顺序和范围，忽略 JSON 元数据；不把 YRC 时间强行对齐另一份 LRC，也不把相邻两句拼成长句。

## 有逐字时间戳

按当前主题 `lyric` 场景 `${text}` 的字体、字号、高度和可用宽度实际栅格测量，把完整计时单元装入一页。下一页使用其首字/首词的时间戳，像普通歌词句一样切换，遵循用户的 MCU 切换动画开关。页内保持静止，不逐字发送画面。

同时起唱的单元合并处理；英文不在没有内部时间戳的词中间捏造时间。某个不可拆单元本身比屏幕宽时，整句回退为两个首尾片段。六套内置主题均使用同一测量和绘图掩码。自定义主题应以独立 `text` 命令、固定矩形和 `text: "${text}"` 定义正文，不在正文占位符中混入装饰。

## 没有逐字时间戳

只生成两个普通时间条目：`开头...` 和 `...结尾`。前页靠左，尾页靠右，末字完整可见；按 Unicode 文本元素切分，不拆开代理对或组合字符。中间省略内容用三个点表示，不再滚动，也不轮出第三页。

设原句开始为 S、下一句为 E，T 为最近传输耗时与启用的过场预算，后页请求时间约为 `S + (E - S - T) / 2 - 0.15 秒`，并限制在开始后与句中点之间。目的是扣除传输/过场后给尾页至少一半阅读时间。该时间在页面计划建立后固定，耗时波动不会使尾页倒退成头页。极短句、跳转进入句尾或 USB 堵塞时，无法保证两页均完整显示；始终优先跟上最新时间轴，不积压过期页。

没有下一句时间、只有播放器当前句时，以短暂的临时时间窗尽早显示尾页；无法保证真实句长的一半，界面注明当前句回退。

## 补偿、最小化与输入

显示选择时间 = 播放器位置 + 刷新延迟补偿 + 手动偏移。默认补偿 **0.8 秒**；手动正值提前、负值延后，默认 0。升级保留个人设置。

本机 **网易云 3.1.41.205564**（模块 PE 时间戳 1791636812、映像大小 41054208）已核对独立播放时钟，关闭桌面歌词、不打开歌曲歌词页并最小化后仍能同步。只读两个 8 字节字段，不注入、不写进程、不读取账号凭据。未知版本不套用地址，回退到有效 SMTC 或原生当前句；本机该版本的 SMTC 时间轴为零，不能代替真实进度。

数值框支持 Enter、点击空白处、切出窗口提交。无效值恢复上次有效值；补偿与手动偏移都参与分页时间选择。

## 验证与资源

分页计划最多缓存 32 项，字形缓存有数量/大小上限。换句、主题或字体变化才重新规划；USB 仍只传目标帧，中间动画由 MCU 执行，保留独占、心跳、退出恢复。

`HaloStudioNet.exe --lyrics-probe --seconds 30 --output <报告路径>` 只读观察播放位置、来源、页码及计时状态，不连接 HID。报告含本机歌曲信息，不应上传公开仓库。`--self-test` 使用原创合成歌词覆盖 YRC、缓存、六主题分页、偏移、暂停/跳转及原有协议回归。测试通过不等同于所有歌曲、播放器版本和 USB 时序都已全面验证。
