# 2.1 验证记录

2026-10-13，本机 Windows x64；.NET SDK 10.0.401，自包含 .NET / Windows Desktop 10.0.12。应用无需 SDK 或 Python。

## 客户端

- Release 发布通过；139 项离线检查全部通过。包含 CRC、RLE、差分、20 组 Python 协议基准、HID 分片、LRC、六主题场景、温度单位、动态包络、独占/释放模拟、整屏动画保护、固件能力分级和外部演示编排。
- 2.1 便携 ZIP 的 312 个文件逐项核对 SHA256；解压后的 EXE 再次通过 139 项检查。包中不含本机安装记录、设置或日志。
- 主题加载隔离无效 JSON/字段类型；新增主题从文件载入，不需改 C#。主题/演示资源在运行时读取。
- 实际 USB 枚举及 C6 版本查询：2D99:A106、MI04、64 字节报告。显示期间使用压缩和差分；差分只依赖已确认帧。
- 修复 IMMDeviceCollection GUID 与网易云 3.1.41 指纹匹配后，多首实际歌曲的实时歌词随当前句更新。用户确认六主题和模拟歌词正常，真实歌词能够出现。
- 有时限的诊断曾在 45 秒后正常退出，造成“程序又退出”的误解；日常启动不带 `--quit-after`，该参数仅供有界测试。
- 最终版完整播放约 59 秒演示后保持运行，UI 和日志均确认回到网易云 3.1.41 当前歌曲，至少八个后续歌词句持续更新。
- 新 UI 分为显示编排、硬件监控、音乐与歌词、演示剧场、设备与运行；上方常驻像素预览，左上保留旧版入口。旧 Python 版仅增加新固件 SHA 识别，功能与界面保留。
- 共用独占锁已实际检查。正常退出会等待在途响应、释放显示并持续回读原厂时钟。TempoHub 运行检查和只读传输探测也遵循独占规则。

## 固件与屏幕

之前的 codec 动画仅覆盖中央区域。C# 曾误将其用于系统监控整屏切换，导致边缘不动；整屏 PC 中间帧虽修复撕裂，但只有一个过渡帧。新增 MCU 全屏动画 ID 3/4 后，用户确认“平滑，全部像素一起移动，结束时钟稳定”，停止心跳后“自动恢复时钟且稳定”。

字符雨固件再增加 ID 5，复用现有缓冲，不新增 RAM。45 组真实 ARM 仿真检查通过（19 生命周期 + 8 codec + 11 全屏 + 7 字符雨），另验证原厂图案/字形、完整 OTA 接收和回退接收。绘图没有触发 Flash 写入。

两次实际升级前均已校验备份。每次 MCU 文件为 57,252 字节、1,041 包；没有发送主控固件。字符雨用户确认：正常重启、下落与标题“全部正常”，停止心跳后“自动恢复时钟，且稳定”。实际 RAM 测试回读也连续保持原厂时钟状态。记录分别保存在本机 `validation/fullscreen-live/` 与 `validation/matrix-live/`。

正常应用运行、主题切换与演示仅写 RAM。新的固件文件只在明确执行升级工具时写入。独立死 MCU USB 恢复仍未证实；文件备份不是完整 Flash 读回，详见固件 README。

## 温度与后台资源

沿用已验证的 44 KB C 温度辅助进程、IPC 和固定哈希驱动资源。本轮未重装驱动；C# 中的 UAC 按钮完整交互尚未重测。Windows/NVML 的内存、磁盘、频率、GPU 负载/温度/功耗/风扇已有本机采样证据，硬件未提供时显示 `--`。

主窗口隐藏时停止 UI 重绘，传感器按需低频采集。像素预览改为缓存位图，只在像素或颜色变化时更新。此前短时观察中，真实歌词后台 CPU 约 0.08%–0.36%（按全部逻辑处理器归一化），工作集约 160 MB；前台演示开销更高。这不是同条件 Python/C# 性能对比，也不是整个系统功耗测量。

历史 2.0 离线预览测量为 C# 工作集 132.77 MB、Python 171.83 MB，但前者没有 USB 传输，不用它断言新程序 CPU 更低。最终打包和后台采样的本机报告保留于 `validation/`。

最终版在完整演示结束后隐藏到托盘，网易云实际播放、USB RAM 显示和音乐灯光同时运行，30.01 秒采样：主进程 CPU 平均 **0.126%**（12 个逻辑处理器归一化）、工作集 **158.88 MB**、私有内存 **67.06 MB**。这是当前配置的一次短时测量，不包含外部温度辅助进程，也不等同于整机功耗。

## 尚有边界

- 网易云未验证版本或不公开歌词的歌曲可能需要 LRC/在线匹配；不保证任意播放器版本的内存布局。
- 桌面预览显示提交目标，不是音响实际中间帧回传；32 ms 是字符雨调度间隔，不是硬件帧率实测值。
- 旧版/新版完整 UI 来回切换和独立温度 UAC 尚未在本轮逐项重测；协议兼容与正常释放已验证。
- 无法保证显示 MCU 完全失效时可独立 USB 恢复，未做破坏性验证。
