# 当前 MCU 与官方 TempoHub 的兼容性实测

测试日期：2026-10-14。这是在一台已验证音响上进行的有限功能检查，不是完整兼容性认证，不保证其他硬件批次、版本或长时间运行都正常。

## 实际环境

| 项目 | 版本 / 条件 |
| --- | --- |
| Windows | Windows 11 专业版 x64，26H2，26300.9457 |
| 官方软件 | EDIFIER TempoHub **1.3.0**（本机安装登记版本） |
| 官方 EXE SHA256 | `688e245659bc90e4589ce91f65f34ef6bdc682bb7f7533dcdcbf777b9f664369` |
| 网易云音乐 | **3.1.41.205564**，测试中持续播放音乐 |
| 音响识别 | Halo PixelBar，USB VID 2D99 / PID A106，MI04；TempoHub 设置页报告固件 **1.3.7** |
| 实际显示 MCU | HPL2 帧内换色／过场版，57,252 字节，SHA256 `9a1b6d1425e980ca1bf9753e0dc1c7ef5ffefde95c741c9a6cf797ace5da237e` |
| HaloStudio | **2.6.0**；测试前正常退出，日志确认释放并稳定恢复原厂时钟，官方测试期间未运行 |

TempoHub 显示的 1.3.7 是其查询到的版本信息，不代表显示 MCU 仍是原厂镜像，也不能用于证明自定义镜像安装成功。此次未刷写固件。

## 结果（逐项区分证据）

| 项目 | 操作与结果 | 证据 |
| --- | --- | --- |
| 识别/连接/设置 | TempoHub 正常识别 Halo PixelBar，首页、灯效、像素屏和设置页可打开，设备页报告 1.3.7 | 软件 UI 观察 |
| 原厂双箭头时钟 | 选择两侧双箭头＋时分秒，完整显示且正常走秒 | 用户实屏确认 |
| 原厂中文主题 | 选择“吉时 已到”，左右中文轮廓、中央时间及日期完整 | 用户实屏确认 |
| 音频播放 | 切回官方显示控制期间，网易云音乐仍正常播放 | 用户听感确认；未测完整音频性能 |
| 官方纯色灯光 | 纯色静光、绿色 `#00FF74`，两侧稳定呈绿色 | 用户实屏确认 |
| 官方亮度 | 从高档改为低档后明显变暗 | 用户实屏确认 |
| 官方自创文字 | 用户在 TempoHub 中手动测试，反馈“文字正常”；未分别确认所有对齐、静态和滚动组合 | 用户手动操作及实屏确认 |
| 官方情绪歌词 | 未完成验证。首次开启后用户反馈仍显示时钟或其他画面；登录 TempoHub 后，软件提示“使用情绪歌词需绑定音乐账号”，本轮未继续绑定 | 用户反馈及软件 UI 提示；不能据此判定 MCU 不兼容 |

官方账号登录不等同于已完成音乐账号绑定。上述情绪歌词结果只说明本轮未满足软件提示的前提，既不是通过，也不是固件故障结论；HaloStudio 自身的歌词同步是另一条实现路径。

其他功能需单独验证。原厂背景与字体的离线一致性检查，不能替代官方软件每一项功能的实物测试。官方图片上传、音乐可视化、天气推送、自创文字的全部排列/动画组合、恢复出厂、再次 OTA、蓝牙/其他输入、断电恢复、智能灯光约 30 分钟空闲行为、所有音效与长期稳定性不在本轮已确认范围。

本记录在 v2.6.0 发布后补充；已发布的标签与应用/固件 ZIP 保持不变，最新结果以仓库主分支的本记录为准。

官方控制器和 HaloStudio 应轮流使用，不能同时占用显示传输。正常释放后原厂路径恢复，不代表原厂软件与自定义直绘可以并行控制同一屏幕。遇到问题请提交 [Issues](https://github.com/woozyc/pixelbardiy/issues)，附版本、场景和已脱敏日志。
