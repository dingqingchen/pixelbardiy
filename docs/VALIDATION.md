## 前序真实设备验证

以下是当前同 SHA 固件与应用的前序验证，区别于本次打包测试：

- 完成 1057 包 MCU 传输后音响自行重启，用户确认恢复正常时钟。
- 猫咪/边框、英文数字、中文歌词完整，用户确认没有“图片上传中”；向上推入与横向揭幕可见。
- 停止心跳后自动回原厂时钟并保持稳定；显式退出亦恢复。旧监控文字反弹问题加入先 RELEASE、后切时钟及稳定核对后，用户确认解决。
- 主题变更异步交接、最新歌词替换，避免排队传输旧画面。
- TrafficMonitor 完全退出/原 WinRing0 未加载时独立 PawnIO 采集成功；再次启动复用 PawnIO；TrafficMonitor 已加载兼容驱动时复用，不另装。空闲真实采样次数不增加，退出后 helper 结束。普通权限被拒绝时不绕过权限。
- 一次六十秒后台观测：整机归一化 CPU 平均约 0.07%，主程序内存约 204 MB，helper 约 5.4 MB；这是本机特定配置的数据。
